# Start here — SkyLens Weather

**One-liner:** A keyless Open-Meteo weather app built around dependent requests — geocode a city, then forecast its coordinates — with debounced suggestions, a unit toggle that never refetches, and full UI states.

**Current phase:** Phase 1 built — static app, not yet deployed.
